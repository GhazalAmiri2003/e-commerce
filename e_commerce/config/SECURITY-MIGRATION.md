# Security migration (development only)

Set DB_HOST, DB_USER, DB_PASSWORD, DB_NAME and DB_PORT in your PHP process environment. Use a non-root account. The original schema is not included; ensure users.password supports at least 255 characters, users.email is UNIQUE, and role accepts user/admin (adapt locally if different). Reset existing plaintext passwords using an administrator-controlled reset process; no plaintext fallback is accepted. Use InnoDB for products and transactional checkout. The revised demo reserves no stock at add-to-cart; it deducts stock at checkout. Before switching an existing installation, stop traffic, clear old sessions and reconcile old reserved stock from reliable records. No order persistence or real payment is implemented. Review session cookie settings (Secure under HTTPS, HttpOnly, SameSite), rate limiting, deployment permissions and remaining endpoints before production. Tests have not been executed.
